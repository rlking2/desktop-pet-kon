## 🖱 启动方式（主人日常用这个）

| 方式 | 命令 | 说明 |
|---|---|---|
| **双击（推荐）** | 桌面上的 **「桌宠」快捷方式** | 或者直接双击 `dist\桌宠便携版\桌宠.exe` |
| 开发用 | `npm start` | 带控制台窗口，方便看日志/报错 |

一键版是**绿色便携包**：整个 `dist\桌宠便携版\` 文件夹（约 370 MB，Electron 运行时占绝大部分）

**Electron 自带的发行版本身就是完整运行时** —— 把 app 放进 `resources\app\`、
把 `electron.exe` 改成 `桌宠.exe`，就是一个独立程序（GUI 子系统 → **双击不弹控制台**）。

**要发给别人用的，用下面这个安装包**（`npm run installer`，见「📦 打包给别人用」）。

⚠️ **同一时间只会有一只桌宠**：第二次双击不会又冒出一只，而是把已经在跑的那只叫到前面，
并让她冒个气泡说「人家在这儿呢～（一次只能有一只哦）」。所以从 `npm start` 换到 exe 之前，
记得先把旧的那只**右键 → 退出**。

## 📝 待办备忘录（左键点击打开）

**左键点击桌宠 → 展开待办面板**（原"随机台词"已替换为此功能）：

| 区域 | 说明 |
|---|---|
| 顶部输入栏 | 输入任务 → **回车添加**；`Esc` 收起面板 |
| 下方栏位 | **两列网格，默认可见 4 栏**（第 25 轮从 5 栏让出一行给「和她说…」）；未填满时显示虚线空槽 |
| **和她说…**（底部那一行） | 打字 → **回车** = 用大模型跟她对话，回复显示在头上的气泡里（见「🤖 让她会说话」） |
| **超过可见栏数** | **列表区域自动变可滚动**（面板尺寸不变，不会跟着任务数抖动）；底部有渐隐提示 |
| 每栏左侧小方框 | **点击 = 完成任务并删除该栏**（先显示删除线反馈，220ms 后移除并重排） |
| 右上角 × | 收起面板（面板隐藏，窗口尺寸不变 —— 列宽固定，桌宠才不动） |

**面板出现的位置**：点击后**桌宠本身不动**，面板直接在她旁边生成（优先左侧，因为桌宠通常贴在屏幕右下角）。
窗口横向扩展（200 → 470）把面板装进去，桌宠的屏幕坐标保持不变（自检有专项断言盯着，实测偏移 0px）。

- 任务**不限条数**，**持久化**在 `localStorage`，重启桌宠仍在
- 添加新任务时**自动滚到底**，保证刚输入的那条一定能看见
- 面板打开时**输入框接管键盘**（Ctrl+M 等全局快捷键不会误触）
- 面板展开时窗口自动放大到 312×430 并**重算穿透掩码**（否则点击判定范围会跟界面对不上）

> 💡 实现要点：滚动高度必须给在**外层容器**上。如果只给 grid 设 `max-height` + `overflow`，
> `grid-auto-rows` 会把行高**压缩**去塞进 max-height，结果是行变矮而不是滚动。

## 📦 打包给别人用（安装包）

**主人只要发一个文件**：`dist-installer\桌宠-安装包-0.2.0.exe`（约 110 MB）。
别人下载后双击 → 选安装目录 → 装完自动启动，桌面/开始菜单都有「桌宠」，控制面板里能卸载。

```powershell
npm run installer        # 生成安装包 → dist-installer\桌宠-安装包-<版本>.exe
npm run installer:dir    # 只解包不压缩（调试用）→ dist-installer\win-unpacked\桌宠.exe
npm run icon             # 只重做图标 → build-resources\icon.ico（默认用 idle 第一帧）
```

### 别人那边会发生什么

| 步骤 | 说明 |
|---|---|
| 双击安装包 | 若 Windows 弹「已保护你的电脑 / 未知发布者」，点 **更多信息 → 仍要运行**（原因见下） |
| 安装向导 | 可改安装路径，**默认装到 `%LOCALAPPDATA%\Programs\桌宠`**（当前用户，**不弹 UAC**） |
| 装完 | 自动启动桌宠 + 桌面快捷方式 + 开始菜单项 + 可在「应用和功能」里卸载 |
| 卸载 | 删程序目录和快捷方式，但**保留 `%APPDATA%\dsh-desktop-pet`**（待办事项在里面，误卸载不丢数据） |

### 三个"为什么不"（都是踩过/想过的坑）

1. **为什么装到用户目录，而不是 `Program Files`**
   桌宠会把原始输入日志写在 `artifacts\`（程序目录里）。`Program Files` 需要管理员权限才能写，
   而按用户安装（`perMachine: false`）既不弹 UAC，日志也写得进去。
2. **为什么必须钉住 `app.getName()`**
   Electron 用 `app.getName()` 拼数据目录 `%APPDATA%\<名字>`。electron-builder 默认会把
   `productName`（中文「桌宠」）注入打包后的 `package.json` → 数据目录变成 `%APPDATA%\桌宠`，
   后果是**便携版里存的待办事项在安装版里看不见**，还会**跑出两只桌宠**（两把单实例锁）。
   所以配置里有 `extraMetadata: { productName: 'dsh-desktop-pet' }` 把它钉回仓库包名，
   并且自检新增了一条断言盯着这件事（改坏了自检会红）。
3. **为什么没有代码签名**
   签名证书要花钱买，所以别人第一次运行会看到 SmartScreen 的「未知发布者」提示。
   想彻底去掉就得买证书（约 ¥1000+/年）后在 `electron-builder.config.js` 里配 `certificateFile`。

### 和便携版的区别

| | 便携版 `npm run exe` | 安装包 `npm run installer` |
|---|---|---|
| 产物 | 一个 370 MB 的文件夹 | 一个 110 MB 的 `.exe` || 发给别人 | 得整个文件夹打包/压缩发过去 | **直接发这一个文件** |
| 安装 | 不用装，双击就跑 | 走向导，建快捷方式，带卸载程序 |
| 依赖 | 无（不需要联网） | 首次构建要联网下载 NSIS 工具链（之后缓存） |
| 数据目录 | `%APPDATA%\dsh-desktop-pet` | **同一个**（所以待办事项两边通用） |

> 注意：本机装完安装包后，桌面「桌宠」快捷方式会指向**安装版**（覆盖便携版那份快捷方式）；
> 卸载后快捷方式会被一起删掉，想继续用便携版就重新跑一次 `npm run exe` 重建快捷方式。

## 🤖 让她会说话（接入 API）

**别人拿到桌宠之后，怎么接自己的大模型** —— 这就是这个功能解决的问题。

### 三步走

| 步骤 | 操作 |
|---|---|
| 1 | **右键点她 → 「设置…（接入 API）」**（独立小窗口；也可以右键桌面那只 → 菜单里找） |
| 2 | 填三样东西：**接口地址**、**API 密钥**、**模型名**（点一下预设按钮会自动填好地址和模型，比如「DeepSeek（默认）」「OpenAI」「月之暗面 Kimi」「通义千问」「智谱 GLM」「本地 Ollama（免费）」） |
| 3 | 点 **「测试连接」**（会真的连一次，成功就显示她回的那句话 + 真实延迟）；然后 **左键点开她 → 在面板底部「和她说…」那一行打字 → 回车** |

她回了话会显示在**桌宠头上的气泡**里（长回复会自动多停几秒，最多 60 字），并且顺手切到「开心」动作。

> 📐 **回复框在她身边**（主人 2026-09-27 定的规矩，实拍 `artifacts/shot-chat-split.png`）：
> **收起面板时气泡在她左上方；面板打开时气泡改到她右上方**（面板**紧贴她左边**、气泡在她右边）。
> 三种东西都是**绝对定位、互不干涉**：人物钉窗口右下角、面板开时钉窗口左边、气泡由 JS 按她的真实矩形落位。
> （第 26/27 轮曾经用 CSS 网格排这三者，只要有一列算不准就会互相挤偏 —— 实测气泡被推到窗口外 -28px、
> 人物被挤出窗口 37px。撤掉网格之后这类问题从根上没了。）

### 🎭 她的性格可以调（第 32 轮新增）

右键 →「设置…（接入 API / 她的话）」里多了两个面板。**核心规矩一条**：

> **没接 API 时，她说的每个字都和以前一模一样**（本地台词，不联网、零 token）；
> **接上 API 之后**，「开心开 / 开心关 / 生气 / 空闲主动开口 / 吃瓜」这五个时机改由大模型现场说，
> 而且说的是**你设定的那个性格**。摸头**永远是本地那三句**（不改，主人明确要求）。

| 面板 | 管什么 |
|---|---|
| **她的性格（人格）** | 身份设定 / 说话风格 / 口头禅与小癖好 / 禁忌 / 例句 —— 五项拼成发给大模型的系统提示词。留空 = 用内置的琴吹紬。另有 **6 个性格预设**（琴吹紬默认 / 温柔体贴 / 毒舌傲娇 / 元气活泼 / 冷静干练 / 完全自定义）一键切换，切完还能逐项手改 |
| **她的话** | 五个时机**逐个开关**（要不要用大模型）+ 空闲开口的间隔/每日上限/静音时段 + 一键静音 |
| **试一句** | 让大模型按**你现在这套人格**当场说一句给你看，并把实际发出去的提示词一并显示出来（看得见才好调） |
| **看看现在的提示词** | 单纯把当前拼好的 system 提示词摊开给你看 |

**两个细节值得知道**：

1. **等模型说完再开口**（主人定的）：点「开心」时她**立刻**做动作，但那句话等主进程拿到模型回复才显示。
   没配 API 时主进程立刻回本地台词，所以感觉不到延迟；真的走模型时会有 1～3 秒只动不说的空档。
2. **连点两下不会串台**：先点「开心」再马上点「收起」，第一趟的回复回来会被丢弃，不会出现"先开心后收起"的话颠倒。

### 🕐 她会自己找你说话（空闲开口）

接上 API 后，你**安静够久**她会主动搭一句。**这条功能自带三重刹车**（不带刹车的"主动开口"就是偷偷烧 token）：

| 刹车 | 默认 |
|---|---|
| 安静多久才开口 | **15 分钟**（可调 1–120 分钟；每次还有 ±25% 的随机抖动，免得像定时任务） |
| 每天最多开口 | **12 次**（可调，`0` = 不限） |
| 静音时段 | **23:00 – 08:00**（可调；两端相同 = 不设静音时段；跨午夜也算得对） |
| 一键静音 | 右键 →「安静一会儿（不要主动开口）」。**只静音主动开口**，你打字跟她聊不受影响 |

另外：**你一理她（点开面板、拖动她、跟她说一句话、打开设置窗口），空闲计时立刻归零** —— 不会出现"刚聊完她马上又主动搭话"。

### 支持哪些接口

**任何 OpenAI 兼容的 `/chat/completions`** 都能用：DeepSeek、OpenAI、Kimi、通义、智谱、各种中转网关、
甚至本地跑的 **Ollama / LM Studio**（`http://127.0.0.1:11434/v1`，一分钱不花）。
地址填到 `/v1` 或直接填到 `/chat/completions` 都行，程序会自己补。

### 密钥怎么存的（重要）

- 存在 **`%APPDATA%\dsh-desktop-pet\api-config.json`**，只在这台电脑上；
- **只由主进程读写** —— 桌宠那个网页界面（`renderer`）和设置窗口都**拿不到真实密钥**，
  它们只能"写入"和看到 `sk-abc••••••••wxyz` 这种掩码。理由：网页里任何脚本都可能读走东西，
  而密钥泄露是要花钱的；自检里有一条断言专门盯着这件事；
- 便携版和安装版**共用同一份配置**（都在 `%APPDATA%\dsh-desktop-pet`），升级不丢；
  换电脑就把这个文件复制过去；
- 卸载安装版**不会删**这个文件（见「📦 打包给别人用」）。

### 设置里能调的（一般不用动）

| 项 | 默认 | 说明 |
|---|---|---|
| 启用对话 | 开 | 关掉 = 完全不联网，仍用本地台词 |
| 活泼程度 temperature | 1.1 | 越高越跳脱 |
| 回复长度上限 max_tokens | 120 | 气泡小，太长会被裁；程序再把回复压到 60 字以内 |
| 记住最近几轮 | 6 | 0 = 不带上下文（最省 token）；接口拒收上下文时自动退回单轮 |
| 超时 | 20000ms | 网络慢就调大 |
| 人设提示词（高级） | 空 | **第 32 轮起请优先用上面的「她的性格」面板**；这一格是"整段覆盖"，填了就盖掉那五项分项人格（老配置因此不会失效） |

### 出错了会怎么样

**不会弹报错框**，她会用自己的口气说一句人话，技术细节写进 `artifacts/input-*.log`：

| 情况 | 她会说 |
|---|---|
| 没填密钥 | （我还没拿到钥匙呢…右键「设置…」把 API 密钥填进来吧） |
| 密钥不对（401/403） | （钥匙好像不对哦，我被门口拦下来了） |
| 余额/额度不够（402） | （额度好像用完了…账户余额得看一下） |
| 请求太快（429） | （问得有点快啦，我缓一口气再说） |
| 模型名写错（404） | （找不到那个模型，设置里的模型名可能写错了） |
| 对面服务器出错（5xx） | （对面服务器打嗝了，过会儿再问我吧） |
| 超时 / 连不上 | （想太久啦…网络或者接口超时了）/（连不上接口，检查一下网络和 Base URL？） |

> 没配 API 时，桌宠**照常能用**：点她还是说本地台词，只是不会"思考"。


- **拖动**：按住紬酱身体**移动超过 4 像素**才开始拖（手动实现，不走 CSS drag 区域）
- **左键点击**：展开待办面板（见上）；面板底部「和她说…」那一行是**跟她说话**（接 API，见下）

    菜单里那一项打勾 = 正在保持中。保持期间鼠标从她身上划过也不会被「靠近」动作顶掉。

  中途移开立即作废、立刻回待机（鼠标一扫而过不会打扰她）。移开后也是**立刻**回待机。
- **Ctrl+M**：菜单的备用入口（万一物理右键在您的环境里不灵）
- **右键 → 「设置…（接入 API）」**：填上自己的大模型接口，她就会用大模型回话（见下面「🤖 让她会说话」）
- **🖱 鼠标穿透**：鼠标移到窗口透明留白上 → 点击直接落到桌面图标；移到她身上 → 正常交互

### ⚠️ 拖动的三条铁律（踩坑换来的，改代码前务必先看）

1. **不能在 `mousedown` 里 `await getBounds()` 再启动拖动**
   —— 真人快速点击时 `mouseup` 先到，拖动循环会被漏关，窗口永久粘在鼠标上
2. **不能在 `mousedown` 里 `preventDefault()`**
   —— Chromium 会因此抑制 `contextmenu` 事件，右键菜单直接不出来
3. **必须有移动阈值（4px）才开始拖动**
   —— 否则点一下的微抖动会让窗口跟着动，`mousedown`/`mouseup` 落在不同坐标，
   **`click` 事件根本不会产生**（症状：点了没反应，但拖动正常）

这三条都在 `renderer/renderer.js` 里有注释，并有对应回归断言盯着。

## 🖱 鼠标穿透是怎么做的

| 步骤 | 做法 |
|---|---|
| 1. 生成「实体像素地图」 | 启动时用 `capturePage()` 截自身图像，alpha 通道降采样 4 倍存成掩码（< 200 KB） |
| 2. 定位鼠标 | 主进程 60ms 轮询鼠标屏幕坐标（鼠标/窗口没动就跳过，几乎不耗 CPU）+ 渲染层 mousemove 即时反馈 |
| 3. 判定 | 命中实体 → `setIgnoreMouseEvents(false)`；命中留白或窗口外 → `setIgnoreMouseEvents(true, { forward: true })` |
| 4. `forward: true` 是关键 | 穿透态下仍能收到 mousemove；否则鼠标一移入留白就「失联」，再也收不回交互权 |

**为什么放弃 CSS `-webkit-app-region: drag`？**
它只认矩形区域，与逐像素穿透天然冲突（留白也会被当成可拖动）。所以拖动改为手动实现：
mousedown 记录按下起点 → 鼠标移动超过阈值后主进程 12ms 循环 `setBounds` 跟随 → mouseup 结束。

**⚠️ 踩过的坑**：拖动时窗口尺寸必须用**设计逻辑尺寸**（200×250），不能回写 `getBounds()` 的结果。
Windows 高 DPI 下 `getBounds()` 返回被吸到物理像素网格的值（200 → 204），
每次拖动都当原尺寸回写的话误差会累积，**窗口会越拖越大**（实测 5 轮漂到 211×261）。
自检里有一条断言专门盯着这个。

## 🔍 自检机制怎么工作的

**第 1 层：Electron 进程内断言（当前素材模式 146 条）**

窗口几何 + 形象渲染 + 穿透掩码判定 + 交互动画 + **真实事件链回归**，其中重点：

| 断言 | 盯的是什么坑 |
|---|---|
| **生成掩码后气泡已恢复可见** | ⚠️ `insertCSS` 不可撤销，曾把气泡永久藏起来（第 4 轮事故） |
| **截图里气泡区域确实被画出来了（像素证据）** | class 加上 ≠ 屏幕上看得见，最终靠数像素判 |
| **真实拖动反复 3 轮尺寸零漂移** | DPI 量化误差累积（第 2、4 轮） |
| **微抖动点击(±3px)仍能出气泡** | 无阈值拖动 → 窗口抖 → `click` 丢失（第 3 轮） |
| **左键按下后紧接右键仍能打开菜单** | `mousedown` 里 `preventDefault()` → `contextmenu` 被抑制（第 3 轮） |
| **快速点击后未卡在拖拽态** | `await getBounds()` 的 race → 窗口永久粘鼠标（第 2 轮） |
| **自检拖动未搬动窗口** | 自检不该污染主人的桌面 |
| **掩码未把窗口边框当成实体** | 调试红框被烧进穿透掩码（第 4 轮） |
| **顶部没有菜单栏** | `setApplicationMenu` 给无边框窗加了菜单栏（第 4 轮） |
| **Ctrl+M 兜底入口可用** | 物理右键再出问题时的退路 |

**第 2 层：截图像素分析（10 条）** —— `scripts/inspect-image.js`

自带 PNG 解码器（zlib + 反滤波），零依赖。检查：内容不贴边 / 未被自检辅助线污染 /
主体占比 / 长发蓝 / 身体浅蓝 / 脸部浅色 / 眼睛深蓝 / 腮红粉 / 尾鳍把重心拉向右 / 轮廓有起伏

> 💡 辅助线不许进截图——自检的调试边框会污染被检对象，所以自检默认关闭红框。

**第 3 层：OS 级穿透验证（独立证据）** —— `npm run probe:clickthrough`

Electron 44 **没有** `isIgnoringMouseEvents()` 这类查询接口，主进程无法自证「OS 层真的变了」。
所以让人家以探针模式启动桌宠（在穿透 ↔ 可交互之间来回翻转），再用 Win32 读取
`GWL_EXSTYLE` 的 `WS_EX_TRANSPARENT (0x20)` 位对照。实测结果：

```
EXSTYLE=0x00280028  WS_EX_TRANSPARENT=True    ← 穿透态
EXSTYLE=0x00200008  WS_EX_TRANSPARENT=False   ← 可交互态
```

**退出码约定**：`0` 全通过 · `2` 有断言失败 · `3` 自检超时 · `4` 自检异常

## ⚠️ 已知限制（人家不吹牛）

1. **动画相位不可复现**：截图落在呼吸动画的随机相位，像素覆盖率每次 ±2% 波动，几何断言已做容差。
2. **高 DPI 尺寸取整**：150% 缩放下逻辑 200×250 被 Windows 吸成 204×254（整数物理像素网格）。
   这是系统行为，不是 bug；断言按 ±4 逻辑像素放行，拖动时已用设计尺寸避免累积。
3. **视觉审美还没验**：当前模型 `deepseek-v4-flash` 不支持图片输入，只能靠像素数学 + 主动报告可疑项。
   **形象好不好看，还得主人亲眼看**（截图在 `artifacts/shot-latest.png`）。
4. **穿透掩码是启动时快照**：目前只在启动后生成一次。以后加「换立绘 / 换表情 / 改窗口尺寸」时，
   形象一变必须重新 `refreshMask()`，否则穿透范围会跟角色对不上。
5. **形象仍是 SVG 占位图**，暂不支持缩放窗口（`resizable: false`）。
6. **PowerShell 脚本带 UTF-8 BOM**：Windows PowerShell 5.1 按系统 ANSI 码页读 `.ps1`，
   不加 BOM 中文会乱码报错。改这些脚本时注意别把 BOM 弄丢。
7. **⚠️ 自检用合成事件，替代不了真实鼠标**：
   `element.dispatchEvent(new MouseEvent(...))` 能覆盖 DOM 事件链，但覆盖不到
   真实物理鼠标与「穿透/鼠标事件分发」的交互、以及菜单在 150% DPI 下的实际显示位置。
   第 3 轮就是**自检 29 条全绿、但真机上点击和右键都是坏的**——因为自动测试用的是
   `pet.click()`，它根本不触发 `mousedown`。**新增交互功能时，务必补"真实事件链"断言，
   并且一定要主人上真机点一遍。**
8. **人家写断言时踩过的同一个坑**：把「正常行为」误判为故障两次——
   `dispatchEvent()` 在 `preventDefault` 生效时返回 `false` 是 DOM 规范行为；
   `getBounds()` 返回被 DPI 吸过的值也是系统行为。**写断言前先做对照实验**。
9. **⚠️ 测试辅助代码本身会成为 bug 来源**（第 4 轮事故）：
   `refreshMask()` 里用 `webContents.insertCSS()` 隐藏气泡来生成干净的穿透掩码，
   但 `insertCSS` **无法撤销**，导致生成掩码后气泡在整个会话里永久不可见——
   而点击处理器照跑、class 照加、`opacity` 计算值还是 1，自检全绿却什么都看不见。
   教训：**临时改动必须可撤销，并且要断言"已还原"**；**"属性对了"不等于"用户看得见"**，
   视觉功能最终要用**像素证据**判。
10. **⚠️ 安装包没有代码签名**：别人第一次双击会看到 SmartScreen「未知发布者」。
    不是病毒，是"没买证书"（见「📦 打包给别人用」）。此外产物是 **x64**，
    ARM64 的 Windows 要靠系统自带的 x64 模拟运行（能跑，但会多耗一点电）。
11. **⚠️ 自检的 121 条断言会用到 `--user-data-dir` 做隔离**（否则会跟主人正在跑的那只
    抢单实例锁，第二个进程直接退出、自检一个报告都写不出来）。所以"打包身份"那条断言在
    隔离模式下只查 `app.getName()`：查 `%APPDATA%\dsh-desktop-pet` 只能靠真机启动。
12. **⚠️ 自检里一条真实 API 调用都没有**（未来也不该有）：自检必须在离线、无密钥的环境下
    全绿，更不能拿主人的密钥去花钱或撞限流。所以"接 API"这件事的覆盖方式是：
    配置读写、密钥不外泄、8 类错误都有台词、真发一次请求到 `127.0.0.1:1`（必失败但走完整链路）、
    输入框 → 主进程 → 气泡这条界面链路。**"接上你自己的密钥能不能聊"只有主人能验。**
13. ~~对话是单轮触发，她不会自己找你说话~~ —— **第 32 轮已实现**（空闲主动开口，带限频 + 静音），见第 18 条。
14. **上下文是内存里的，重启就没了**：只在一次运行期间记住最近 N 轮（默认 6 轮）。
    落盘持久化会牵出"隐私/体积"两个问题，暂时不做。
15. **⚠️ 在 DSH 会话里跑 Electron 命令前必须先清 `ELECTRON_RUN_AS_NODE`**（第 31 轮）：
    会话环境里这个变量会让 Electron "只当纯 Node 跑"，`require('electron')` 只返回一个 exe 路径字符串，
    症状是 `main.js:82 TypeError: Cannot read properties of undefined (reading 'requestSingleInstanceLock')`
    —— **看着像代码坏了，其实是环境变量**。修法：`Remove-Item Env:ELECTRON_RUN_AS_NODE` 后再 `npm start` /
    `npm run verify`。主人自己在普通终端里跑不受影响（`npm run exe` 也不受影响，它不启动 Electron）。
16. **⚠️ 「走模型」的时机每次都要花 token**（第 32 轮）：打勾的时机（开心开/关、生气、空闲开口、吃瓜）
    每次都会真的发一次请求、烧一次 token。**摸头永远是本地的**，不花钱。怕费 token 就去设置里
    把对应时机取消勾选，或右键「安静一会儿」把主动开口一次性关掉。
17. **⚠️ 气泡台词有时会"慢半拍"**（第 32 轮，主人选的行为）：按「等模型说完再开口」，
    点「开心」时她**立刻**做动作，但那句话要等模型回来（1～3 秒）才出现，这段时间她只动不说。
    没配 API、或调用失败时会立刻念本地台词，所以感觉不到这个空档。
18. **⚠️ 空闲开口只在"真的安静够久"之后才可能触发**：默认 15 分钟，且每次还有 ±25% 的随机抖动。
    想马上看她主动开口，可以用设置里的「试一句」（它走的是同一个提示词）。
19. **⚠️ 窗口比看得见的部分宽**（第 26 轮）：收起面板时窗口也是"三列"宽（约 660px），
    左边那两列是**透明 + 逐像素穿透**的，肉眼看不见、也点不到、不影响底下的桌面图标。
    这么做的原因写在 `devlog/round-26.md`：宽度一变，CSS 网格的列就会整体平移，
    桌宠和气泡会跟着跳（实测分别跳 461px / 248px）。**固定列宽 = 画面稳定**。
20. **⚠️ 形象素材可能还是旧角色的**（第 33 轮换人**只改了文字**）：台词与人格已经换成琴吹紬，
