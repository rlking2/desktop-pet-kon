# 🐋 鲸鱼娘桌宠（DSH 官方拟人化形象）

深海蓝长发 + 鲸鱼尾鳍 + 女仆装的桌宠。自称「人家 / 本鲸」，主食是白饭（token）。

**当前进度：阶段 0 完成** —— 透明无边框置顶窗口，能拖能跑，有互动反馈，带自动自检。

---

## 快速开始

```powershell
npm start          # 启动桌宠（常驻在桌面右下角）
npm run autotest   # 一键自检：窗口状态 + 交互 + 截图 + 15 条断言
```

- **拖动**：按住鲸鱼娘本体拖，窗口跟着走
- **左键点击**：她会蹦一下并说话
- **右键**：菜单（摸头 / 喂白饭 / 永远置顶 / 回到底部右侧 / 退出）
- `DSH_PET_DEBUG=1 npm start` 会画出红色窗口边框，方便看边界

## 🔍 自检机制怎么工作的

桌宠是图形程序，光跑命令看不出好坏，所以做了两层：

**第 1 层：Electron 进程内断言（15 条）**

窗口可见 / 永远置顶 / 尺寸符合设计（高 DPI 有 ±4 逻辑像素容差）/ 完整落在工作区内 /
透明背景 / 形象已渲染 / 尾鳍存在 / 待机动画在跑 / **拖动区域 drag 生效** /
截图非空白 / 无渲染错误 / 点击出气泡 / 蹦跳动画 / 摸头脸红 / 生气状态 / 窗口未跑位

**第 2 层：截图像素分析（`inspect-image.js`，10 条）**

自带 PNG 解码器（zlib + 反滤波），不依赖任何第三方库。检查：
内容不贴边 / 截图未被自检辅助线污染 / 主体占比 / 长发蓝 / 身体浅蓝 / 脸部浅色 /
眼睛深蓝 / 腮红粉 / 尾鳍把上半身重心拉向右 / 轮廓有起伏（不是方块）

> 💡 辅助线不许进截图——自检的调试边框会污染被检对象，所以自检默认关闭红框。

**退出码约定**：`0` 全通过 · `2` 有断言失败 · `3` 自检超时 · `4` 自检异常

## ⚠️ 已知限制（人家不吹牛）

1. **动画相位不可复现**：截图落在呼吸动画的随机相位，所以像素覆盖率每次有 ±2% 波动。
   几何类断言已做容差，颜色类断言不受影响。
2. **高 DPI 尺寸取整**：显示器 150% 缩放时，逻辑 260×320 会被 Windows 吸成 264×324（整数物理像素网格）。
   这是系统行为，不是 bug，断言按 ±4 逻辑像素放行。
3. **视觉审美还没验**：当前模型 `deepseek-v4-flash` 不支持图片输入，人家只能靠像素数学 +
   主动报告可疑项。**形象好不好看，还得主人亲眼看**。等切换到有视觉能力的模型，人家就能自查审美了。
4. **暂时不能改尺寸**：`resizable: false`，形象还是 SVG 占位图，换立绘时再放开。
