## ① 悬停 0.5 秒的规矩

原来"鼠标一进角色矩形就播「靠近」" —— 鼠标路过也会触发，很吵。现在按主人要求改成**延时触发**：

| 动作 | 行为 |
|---|---|
| 鼠标进入/停在她身上 | 起一个 **500ms** 定时器；到点**还停着**才播「靠近」（一次悬停只播一次） |
| 中途移开（不到 500ms） | **立即作废**定时器，不播；计数一次"中途作废" |
| 停满 500ms 之后再移开 | **立即**取消 + 立即回待机（不等、不拖泥带水） |
| 保持动作（开心）期间 | 照旧不顶掉姿势（原来那条规矩不受影响） |

判定仍然是**逐像素**（第 27 轮加的）：矩形四角是空气，不算"在她身上"。

### 自检里新增的 3 条断言（把"没到点不许播"和"到点必须播"都钉住）

```
PASS  鼠标刚靠近（不到 0.5 秒）**不播**触碰动画（鼠标一扫而过不打扰她）
      (悬停 200ms 时：hovering=false 当前动作=idle 定时器等待中=true)
PASS  悬停满 0.5 秒 → 切到「靠近」动作
      (延时设置=500ms 真正触发次数=1 当前动作=hover)
PASS  悬停没满 0.5 秒就移开 → 不播「靠近」，立刻回待机（中途作废次数=1）
PASS  作废之后重新悬停 0.5 秒 → 「靠近」动作照常触发
```

## 顺手修掉的两个"红"

1. **两条旧的"事件断了也有兜底"断言变红**：它们先移进去、再打开兜底心跳，
   而兜底心跳看的是**真鼠标**（自检用合成事件，真鼠标在屏幕别处）→
   它一开就把"刚设好的 hover"改回待机。修法：**在打开兜底之前**先取一次
   "移入后 hovering=true"的观测，后面复用这个观测。
   （原来能用是因为"移入"是同步生效的；现在多了 500ms 延时，中间的空档就被兜底抢了。）
2. **打包版偶发红一次**（`面板 [0,0]`）：打包版启动比开发版慢，偶发"面板还没展开就发消息"，
   于是面板矩形量出来是 0。已在聊天测试前面补了一道保险：**先确认面板真的开着**再打字。
   加完连跑两次便携版自检都是 121/121。
