# 第 16 轮：给每一帧加描边（参考主人给的左边那只桌宠）

主人的原话：**「我想参考左边的那个桌宠，对我们桌宠的每一个帧进行描边，描边颜色与左边的类似」**
（附了一张两只桌宠并排的截图：左边是银发红领结那只，右边是我们的）。

## 一、先把"左边那只的描边到底是什么颜色"量出来

这件事不能靠感觉 —— 人家在主人给的图上做了两种测量：

| 测量 | 结果 |
|---|---|
| 她轮廓**最外侧**的像素（左侧 260 行）平均色 | `rgb(123,123,149)`（深色与紫色背景的混合） |
| 其中**很白**（>235）的比例 | **0%** |
| 其中**很深的黑**（<90）的比例 | **24%** |

→ 结论：**左边那只的描边是近黑色的线稿**，**不是白色贴纸圈**（人家一开始也以为她有一圈白边，
放大看才发现那是她自己的白发/白衬衫 + 黑线稿）。所以描边色取**近黑 `#141414`**。

粗细也对了一下：她的线稿 ≈ 3.3px / 角色高 265px ≈ **1.25%**；
我们角色屏上高 169px → 约 **2px** ✓ 所以定 `width: 2`（屏幕像素）。

## 二、为什么画在渲染层，而不是把描边烘进素材

`renderer.js` 的 `drawSpriteFrame()` 里做的：

```js
const OUTLINE = { color: '#141414', width: 2 };
```

每帧绘制时：**先把这一帧的 alpha 形状填成纯色剪影**（离屏 canvas + `globalCompositeOperation = 'source-in'`），
按 16 个方向各偏移 `width` 像素画一遍，**最后再把原图盖上去** → 得到一圈干净的描边。

三个理由：

1. **"每一帧"自动成立** —— 包括以后新加的素材帧，不用每次重新导图
2. **粗细在屏幕像素上恒定** —— 素材做过 `--normalize-height`，同一张图在不同组里的缩放比是
   0.12~0.39（差 3 倍），**烘进素材的话，粗细分到各帧就不一样了**
3. **素材保持原画** —— 想关掉就 `width: 0`，想换色就改一个字符串

顺带处理了一个细节：绘制时要**给描边留边距**（`pad = width + 1`），否则贴到画布边缘的那几帧
（比如「开心」那三帧正好铺满宽度）描边会被画布裁掉一圈。

## 三、自检：98 → **99/99 ✅**

新加的这条不是只读配置值，而是**在画布像素上取证**：

> 找"轮廓外侧 3px 已经透明、内侧 8px 还是亮色"的位置，要求最外 1px 是描边色。
> 这样能证明**描边真的画在轮廓上了**，而不是"代码里配了但没生效"。

```
PASS  每一帧都套用描边，且描边真的画在轮廓上（画布像素取证）
      (描边=#141414 2px 方向数=16 已缓存剪影=2；画布 167x200 上"亮色轮廓 + 外侧描边"的取样点 56 个
       （例：117,20 / 117,21 / 118,21 / 118,22）)
```

其它副产物证据：**不透明覆盖率 13.2% → 17.4%**（描边把轮廓加粗了一圈，符合预期）。

> 放大看时会看到头发里有彩虹色竖纹 —— 那是**原图印品的条纹纹理被缩小时产生的摩尔纹**，
> 之前就有（不是描边弄的），屏上实际大小看不出来。
