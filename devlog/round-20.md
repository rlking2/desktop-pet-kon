# 第 20 轮：白蝴蝶不描、线条更细、（手：查清了但没完全做到）

主人的原话（附了两张实机截图）：

> **「这里的白色蝴蝶可以不描，第二张图的手可以描一下，还有线条还是太粗了，有没有更细的」**

## 一、线条更细 ✅

| | 之前 | 现在 |
|---|---|---|
| 掩码的"预加粗" | 2~4 源像素（≈1px 屏上） | **1~2 源像素（≈0.5px 屏上）** |
| 滑条步进 | 1px（0/1/2/3/4） | **0.25px（0 ~ 4）** |
| 默认值 | 1px | **0.5px** |
| 外轮廓 | 单独一项 1px | 跟部件线**同一档**（一个滑条管两处） |

`scripts/preview-compose.js idle --width=0.5 ...` 就是按屏上真实尺寸合成的效果，
人家核对过：线变成很细的一道，头发/手/腿的轮廓还在，裙子条纹依旧不描。

> 想更细还能到 0.25（滑条最小档）；0 就是完全不描。

## 二、白蝴蝶不描 ✅

"白色蝴蝶"= 靠近动作里那片压在脸上的白叶子（第 15 轮特意留下的那片）。
做法：在渲染层加了一张**不描区域表**（归一化矩形），把这一块从
**外轮廓层**和**部件线层**里都挖掉 —— 人物本体照常画：

```js
const OUTLINE_EXCLUDE = {
  hover: [{ x: 0.20, y: 0.30, w: 0.24, h: 0.28 }],   // 白蝴蝶
};
```

自检里新加了 `artifacts/shot-hover.png`：**趁「靠近」动作正在显示时抓的图**，
主人可以直接对着核对"白蝴蝶有没有被描"。以后要挖别的地方，照这个格式加一行就行。

## 三、手：查清了原因，但只做到一半（要主人定）

**能描到的**：手与**脸/头发**的交界（这条已经画出来了 ✅）。
**还没描到的**：手与**黑裙子**的交界 —— 因为**手和裙子都是黑的**（同一色系），
"按颜色分部件"这条根子上就分不开；中间那条原画的轮廓线又被分割算法和周围黑块合并掉了。

人家试了三种办法，都有代价：

| 办法 | 结果 |
|---|---|
| 分割调细（tol 140 → 70） | ✅ 手描出来了，❌ **裙子条纹也被描了**（条纹边的暗影带被当成部件） |
| 允许"两块深色也算相邻"（tol=70/100） | ✅ 手描出来了，❌ 条纹照旧被牵连 |
| 再加"必须够紧凑（填充率≥0.35）" | ✅ 条纹干净了，❌ 手又丢了（手套形状的填充率不达标） |

**当前选的**：`tol=140`（**条纹干净**，主人上一轮明确要的"裙子只勾最外层"不破功），
代价是**手与裙子那一段没描**。手与脸/头发那一段是有的。

> 想把"手 vs 裙子"也描上，最稳的办法是**手工给手套圈一个区域**（跟白蝴蝶反过来：
> 变成"额外要描"的矩形），然后在那块区域里把原画的深色轮廓线描出来。
> 主人要是要，给人家一句话，人家加一张"补描区域表"就行（那张表也是几行配置）。
