# 第 13 轮：清掉素材里的「页面残留」（白线 / 右下白线框）

主人的原话：**「检查一下待机动画，有几帧下方有白线，右下也有白线框」**。

## 一、先查清楚是什么

拿工具把那三张待机素材翻出来量（不是靠肉眼猜）：

```powershell
node scripts\clean-pagemarks.js     # 这一轮新写的工具（先体检，不写文件）
```

量出来的东西跟主人描述完全对得上，而且**不止待机组有**：

| 残留 | 长什么样 | 出现在 |
|---|---|---|
| **页面下边框的灰色横线** | 2px 高、横贯画面、`rgb(43,43,43)` 但 **alpha 只有 60** —— 合成到浅色桌面上 ≈ `rgb(205,205,205)`，所以主人看着是"白线" | `idle/frame-02`（→ 成品 `idle/frame-001`） |
| **右下角的粉色页码徽标** | 圆角方框 + 数字（这张是 **8**，另一张是 **6**）+ 一个粉色水滴，粉色线稿 | **八个源图里全都有**（idle ×3、interact ×3、hover、happy） |
| 左上角的**淡粉圆弧** | 一段大圆弧（邻格画面残留） | idle/frame-02、interact/frame-01/02/03、hover |
| 画布边角的**灰色小印子** | 十几像素的小污点 | idle/frame-01/03 |

> 为什么人家一开始没发现：这些像素**透明度太低**，看 `opaqueRatio`、看 bbox 都会被当成噪声，
> 而且人家以前"看不见图"。这次是把素材**合成到浅色底上再放大**才看清的
> （深灰 alpha 60 合成到浅底 = 浅灰，这正是主人看到"白线"的原因）。

## 二、差点删错东西（本轮最大的坑）

第一版判据只看**颜色**：粉色像素占比 ≥ 45% 就当成页码线稿。
在 `interact/frame-03` 里立刻撞上了一块 **4903px 的粉色叶子**（粉=0.71、avgA=76）——
它是跟白/黄/橙/紫叶子**同一套的装饰**（同一片叶子形状，还有叶脉），
只是叶肉偏白、抠背景时被吃掉了一部分，所以又淡又粉。

**判据里必须再加"形状"这一维**：

| | 填充率（面积 ÷ 包围盒） |
|---|---|
| 页码框 / 圆弧 / 页面边框线（**线稿**） | **0.01 ~ 0.18**（笔画细，中间是空的） |
| 叶子一类的紧凑色块 | **0.30 ~ 0.69** |

于是最终判据是五条（按顺序，先"豁免"再"定罪"）：

1. `avgA ≥ 200` → 实心，是画面内容，不动
2. **填充率 ≥ 0.30 且 ≥ 300px → 紧凑色块（叶子/装饰），留着** ← 就是这条救回了粉叶子
3. 粉色像素占比 ≥ 45% → **粉色线稿**，删
4. 中性深灰占比 ≥ 40% → **页面边框线/角标**，删
5. 暖深色（棕黑）占比 ≥ 35% → "白叶子"，留着
6. 其余：< 100px 且 avgA ≤ 120 的极淡点 → 当噪点删；**拿不准的一律留着**

## 四、副产品：她变大了（这是好事，但要主人知道）

残留物**把"内容包围盒"撑大了**，而整个流水线是按包围盒高度归一化的
（每组统一到"该组最高帧 × 85%"）—— 也就是说：**残留越大，角色在屏上越小**。

清完之后各组的包围盒都收紧了：

| 组 | 画布 | 屏上角色主体高 |
|---|---|---|
| idle | 901x1203 → **858x1027** | 119~135px → **147~165px** |
| interact | 484x659 → **450x629** | 141px → **166px** |
| hover | 687x987 → **687x856** | 144px → **167px** |
| happy | 687x1090 → **687x942** | 127px → **147px** |

- 显示框（按最宽素材的宽高比算）从 **150x200** 变成 **167x200**，窗口还是 200×250
- 自检里的几何/掩码断言全部照过（掩码实体占比 11.5% → 15%：她确实占了更大一块）

**如果主人觉得"变大不好看"，说一声就能按像素比例缩回去**（在 `inspect-assets.js` 的
`--normalize-height` 目标上乘个系数即可，不用重新导图）。

## 五、还发现一件事：两片「白叶子」是被抠坏的（没删，等主人定）

`idle/frame-02` 和 `interact/frame-02` 里各有一片**白色叶子**装饰：
叶肉偏白 → 抠背景时被一起抠掉了 → 现在只剩深色轮廓 + 半透明叶脉，
看着像一个"白色空心云朵"。

它是**画的一部分**（跟黄/橙/紫叶子同一套，形状、叶脉都一样），所以**没删**。
要修的话有两条路（主人选）：

1. **把叶肉补回白色**（按轮廓内部填充白色，变成一片实心白叶子）—— 需要新写一段"填洞"逻辑
2. **整片删掉**（当它不存在）—— 一条规则的事，但装饰会少一片
