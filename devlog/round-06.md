# 第 6 轮：剥离鲸鱼主题，只留通用机制

日期：第 6 轮开发
主人要求：「接入机制先去掉，桌宠主题不是鲸鱼，之后会额外设置」

## 理解与决策

主人不是要拆掉帧动画管线（那是上一轮刚建的），而是要**把"鲸鱼"这个具体主题从代码里剥掉**，
让形象完全由素材决定，主题以后单独设置。

所以这一轮做了"**去主题化**"：机制全留，主题全走。

## 改了什么

| 位置 | 改动 |
|---|---|
| `renderer/index.html` | **删掉整个内联 SVG 鲸鱼**（约 60 行渐变/路径/腮红） |
| `renderer/style.css` | 删掉所有形象相关样式（`.whale`、呼吸、眨眼、尾鳍、深海蓝配色）；气泡与名牌改成中性灰蓝 |
| `renderer/renderer.js` | **重写**：只剩通用机制（canvas 渲染 / 帧动画 / 空位提示 / 互动 / 拖动 / 穿透上报 / 诊断） |
| 台词 | 去掉"甩尾鳍""鲸鱼的特征"等主题台词，换成中性短句 |
| `main.js` | 窗口标题、菜单、日志头、关于文案全部中性化 |
| `package.json` | 包名 `dsh-whale-pet` → `dsh-desktop-pet` |
| 自检断言 | 删掉"尾鳍元素存在"等主题断言，换成"角色画布存在且尺寸正确" |

**保留不动**：帧动画播放器、动作优先级、素材管线（拆帧/对齐/体检）、穿透、拖动、
气泡自动翻面、原始输入日志、全部回归断言（共 50 条）。

## 关键设计：空位提示（placeholder）

剥掉鲸鱼之后，窗口里就没东西了。但这会引发一个**致命连锁问题**：

```
没有可见内容
  → 穿透掩码全是空气（实体占比 0%）
  → 主进程判定鼠标永远在"窗口外/空气上"
  → setIgnoreMouseEvents(true) 一直生效
  → 鼠标事件根本进不到窗口
  → 点击、拖动、右键全部失效，主人以为桌宠坏了
```

所以加了一个中性的**空位提示**：一个淡色虚线圈 + "等待素材"字样。

它同时满足三件事：
1. 主人一眼就知道**该往 assets/ 放图了**
2. 掩码仍有实体（实测实体占比 12.1%），**点击/拖动/穿透全部正常工作**
3. 视觉上完全中性，不预设任何主题

> 填充透明度踩了个坑：一开始用 `rgba(...,0.34→0.10)` 的渐变，结果掩码阈值
> （`ALPHA_THRESHOLD=90/255≈0.35`）把整个填充判成了空气，只有虚线还算是实体，
> 导致"环内"点不到。改成 `0.55→0.42→0.18` 后实体占比从 6.2% 升到 12.1%。

## 顺手修掉的断言缺陷

「中心命中实体」这条断言原来假定"窗口正中心一定是实体"——对鲸鱼成立，对空位环**不成立**（环中心是空的）。

一开始改成"窗口内按 10% 网格扫描找实体点"，结果 32 个点只有 1 个命中（网格太粗，采样靠运气）。

最后改成：给穿透模块加 `findSolidPoint()`，**直接在掩码里从中心向外逐环扫**，
返回第一个实体像素的掩码坐标并换算成屏幕坐标。这样取样精确，跟形象形状无关。

## 以后加主题要改哪里（给未来的自己）

1. **形象**：往 `assets/<动作名>/*.png` 放帧序列，跑 `npm run assets:write`，什么都不用改
2. **台词**：`renderer/renderer.js` 里的 `LINES` 对象（中性短句，可换成主题化台词或读配置）
3. **名牌**：`renderer/index.html` 的 `.name` 文本
4. **配色**（气泡/名牌）：`renderer/style.css` 里 `.bubble` 与 `.name`
5. **不要**再往代码里塞具体形象（SVG/渐变/主题色）——第 6 轮就是把它全拆出来的

## 已知限制

1. **空位提示是代码画的**，接到主人素材后会自动消失（`spriteState.available = true`）
2. 素材的**帧率仍需主人定**（默认 120ms/帧），改 `assets/manifest.json` 即可
3. 人家**看不见图**，审美与挑帧必须主人来（模型不支持图片输入）
