# 第 19 轮：按部件描边（头发/眉毛/手/裙子外层/腿脚）+ 两条横条

主人的原话：
> **「接下来我给你仔细指出要描的地方：头发，眉毛，手，裙子只勾最外层，腿和脚，
>   勾线的粗细黑白深度两项同之前调播放速度一样给我两条横条」**

## 一、要描哪些部件 —— 靠"颜色分区"自动认

上一轮（第 17 轮）那种"按色差找边线"的做法做不到这件事：它分不清"裙子外轮廓"和"裙子上的黑白条纹"
（两者都在黑白交界上），也分不清"头发的轮廓"和"头发内部的深浅花纹"（后者色差甚至比前者还大：
受光金 196,172,133 vs 背光金 124,113,95 差 169，而"头发 vs 肤色"只差 114）。

所以这一轮换了思路，新工具 **`scripts/make-edge-masks.js`**：

```
① 容差泛洪，把画面切成"颜色区域"
② 把区域分成两类：面积 ≥ 900px 的是**部件**，比它小的是**线**（原画的描边线）
③ 判"两个部件要不要画线"，用的是**部件自己的平均色**：
     · 同一色系（都是头发 / 都是暗色 / 都是皮肤…）→ 不画  ← 头发内部花纹靠这条挡掉
     · 色差 < 110 → 不画
     · 「深色 ↔ 白色」这一对 → **不画**  ← 裙子黑白条纹靠这条挡掉（= "只勾最外层"）
     · 隔着一条"线"相邻的两个部件，也算相邻（拿线当桥，不去合并区域）
④ 把"该画线的部件交界"那薄薄一层像素写成掩码 PNG
   （按屏上缩放比**预先加粗**，缩到 167x200 后正好约 1px）
```

**踩过的两个坑**（都写在脚本注释里了）：

| 坑 | 现象 | 修法 |
|---|---|---|
| 直接比色差 | 整个刘海被涂红（头发内部花纹） | 加"同一色系不画" |
| 把"线"并进邻居再判 | 区域平均色被污染，眼睛和裙子条纹都被描成红块 | **不合并**，改成"拿线当桥"判邻接 |

调参全程用两个离线工具（不用跑 Electron，几秒一轮）：
`make-edge-masks.js --preview`（原图+红线对照）和 `preview-compose.js`（**按屏上真实尺寸**合成，看最终效果）。

**产物**：`assets/build/edges/<组名>/<帧名>.png`（8 张，跟成品帧同名同尺寸），
运行时由 `lib/assets.js` 自动按 `build/frames/ → build/edges/` 找到并交给渲染层。

## 二、两条横条（就在待办面板里）

主人说"同之前调播放速度一样"—— 所以沿用了当年那个调速滑条的做法：
**左键点开待办面板**，面板里多了一行两条横条（同一行，省高度）：

```
描边粗细 ▮—————— 1px     黑白深浅 ▮——————  92%
```

| 滑条 | 范围 | 作用 |
|---|---|---|
| **描边粗细** | 0~4 px | 部件线 + 外轮廓的粗细；**0 = 完全不要描边** |
| **黑白深浅** | 0~100 | 线色：0 = 纯白，100 = 纯黑（默认 92 ≈ `rgb(20,20,20)`，就是量参考图得到的那种近黑） |

拖动**立即生效**（清掉缓存 → 下一帧重画），不用重启。
自检入口也留了一个：`window.__petTest.setOutline(粗细, 深浅)`。

## 三、自检：99 → **103/103 ✅**

新增 4 条，都是**像素取证**而不是读配置：

```
PASS  描边两条横条存在（粗细 0~4 / 黑白深浅 0~100）
PASS  拖"描边粗细"滑条 → 画布上的线条跟着变粗/消失（像素取证）
      (粗细0时深色像素=2390，粗细4时=5627（默认1px时=4502）)
PASS  拖"黑白深浅"滑条 → 线条颜色跟着变深/变浅
      (深浅20 → rgb(204,204,204)（深色像素 2188）；深浅95 → rgb(13,13,13)（深色像素 4564）；恢复默认 → rgb(20,20,20))
PASS  部件描边掩码已接入（头发/眉毛/手/裙子外层/腿脚）
      (带掩码的动作组=[idle, interact, hover, happy]；外轮廓=1px；已缓存掩码层=2 剪影=2)
PASS  每一帧都套用描边，且描边真的画在轮廓上（画布像素取证）（取样点 30 个）
```

> 顺带修了一个自己写错的断言：第一版把"画布探测结果"当成了"setOutline 的返回值"，
> 于是"颜色"永远读到 undefined —— 这也是为什么断言必须带**可读的数值**（一看详情就露馅）。

## 四、一个已知的"副作用"，等主人定

外轮廓那一圈是跟着**整帧的 alpha 形状**走的，所以**「开心」「摸头」那些飘着的彩纸也被描了一圈**。
要的话可以改成"只描人物本体"（人物掩码 + 彩纸不描），说一声就行。
