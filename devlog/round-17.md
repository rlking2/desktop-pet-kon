# 第 17 轮：描边细化（线条改细 + 头发/手也描上）

主人的原话：**「线条太粗了，而且我希望连带头发和手都描一下」**。

## 一、线条改细：2px → **1px**

上一轮按"参考图线稿占身高 1.25%"算出来是 2px，主人说太粗 —— 直接减半。
（`renderer.js` 里 `OUTLINE.width`，现在是 1 屏幕像素；DPR 1.5 下 = 1.5 物理像素，够细也够清。）

## 二、"头发和手也描一下"：加**内部边线**

### 为什么原来是空的

上一轮只描了**外轮廓**（alpha 形状的边缘）。而她**手压在脸/胸口上**、**头发压在脸上**，
这些地方两边都是实心像素 —— 外轮廓根本不经过那里，所以看着就是"没描"。

### 第一版做法错在哪（值得记）

朴素做法：**比对相邻像素的色差，差异大的就描成线**。结果——

> 脸上、裙子上、头发里全是**黑麻点**，比不描还难看。

原因：素材是**印刷品扫描**，头发里有细条纹纹理，再叠上缩小产生的**摩尔纹**，
这些"纹理"的局部色差也不小 → 全被当成边线了。

### 现在的做法（三步，缺一不可）

```
① 先模糊 1px          ← 把印刷纹理/摩尔纹抹平（关键一步）
② 找强颜色边界         ← 相邻像素三通道差之和 ≥ 120
③ 删掉面积 < 12px 的碎片 ← 剩下的零星麻点清掉
④ 把这些像素染成描边色（保留 alpha）
```

调参没有反复跑 Electron（一轮 40 秒太慢），而是写了 **`scripts/preview-outline.js`**：
在 Node 里复现"缩放 → 内部边线 → 外轮廓"三步，直接出图，**几秒一轮**。参数就是在它上面定的：

| 参数 | 试过的值 | 结论 |
|---|---|---|
| 做法 | `quant`（色块化）/ `grad`（模糊+梯度） | 色块化在屏上尺寸（角色才 91~163px 宽）**碎成 1785 个块**，几乎找不到"大色块" ✗ → 用 `grad` |
| 模糊半径 | 1 / 2 | 2 太狠（阈值 160 时一个边线都找不到）；**1** 最平衡 |
| 阈值 | 70 / 90 / 120 / 160 | 70 偏脏、160 全空；**120** 干净且头发/手/耳环/裙边的线都出来了 |
| 最小碎片 | 12px | 刚好把麻点清掉，又不误删短边线 |

## 三、效果与验证

```
自检        99/99 ✅（那条"画布像素取证"的描边断言照过：33 个取样点）
目视        1:1 截图：外轮廓 1px 细线；**手（黑手套）与脸/胸口的交界、头发与脸/黑蝴蝶结的
            交界、绿耳环、裙边都描上了线**，且没有麻点
打包版自检  99/99 ✅
```

> 放大 3 倍仍能看到头发里的彩虹色细纹 —— 那是**原图印品纹理缩小后的摩尔纹**（之前就有，
> 也是人家第一版翻车的原因）。屏上 1:1 看不出来。要彻底消掉得把素材本身去网纹，另说。
