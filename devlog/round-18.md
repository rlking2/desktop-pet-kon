# 第 18 轮：退回上上版（去掉描边）

主人的原话：**「退回到上上版」**。

## 一、先确认"上上版"是哪一版

人家把最近几轮的"版"列出来对齐（免得退错了）：

| 轮次 | 那一版的样子 | 相对现在 |
|---|---|---|
| 第 15 轮 | **没有描边**（清完"靠近"动作的彩纸） | ← **上上版**（退回到这里） |
| 第 16 轮 | 描边：**2px 近黑、只有外轮廓** | 上一版 |
| 第 17 轮 | 描边：**1px + 头发/手的内部边线** | 现在这一版 |

"上上版" = 往回数两版 = **第 15 轮 = 描边之前的样子**，所以这一轮把描边整个关掉了。

## 二、怎么退的（代码没删，一句话能切回去）

`renderer.js` 顶部：

```js
const OUTLINE = {
  color: '#141414',
  width: 0,        // ← 原来是 1
  inner: false,    // ← 原来是 true
  ...
};
```

关掉之后 `drawSpriteFrame()` 直接走"画原图"那条老路，**下面那套处理一行都不跑**（零开销）。

想切回去只要改这两个数：

| 想要的效果 | 配置 |
|---|---|
| 第 16 轮（只有外轮廓，2px） | `width: 2, inner: false` |
| 第 17 轮（1px + 头发/手内部边线） | `width: 1, inner: true` |
| 现在（不要描边） | `width: 0, inner: false` |

改完**重新打包**（`npm run exe`）或直接 `npm start` 看；内部边线的参数还能用
`node scripts/preview-outline.js` 几秒预览一次。

## 三、验证：**和当时那张截图逐字节相同**

| 证据 | 值 |
|---|---|
| 自检截图 SHA256 | `7aa65d7e2d225416…`（**与第 15 轮那张一模一样**，说明画面完全退回去了） |
| 自检 | **99/99 ✅** —— 描边那条断言现在是反向的：`描边已按要求关闭（退回上上版）`，并报出"亮色轮廓+外侧描边"取样点只有 2 个（开着的时候是 33 个） |
| 打包版自检 | 99/99 ✅ |

> 人家特意把断言改成**两态都能自检**（开着就取证"真的画上了"，关着就取证"确实没画"），
> 这样以后来回切换都不会出现"代码改了但自检还是绿的"那种假安全感。
