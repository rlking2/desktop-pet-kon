# 第 22 轮：把主人调好的两个值固化（0.25px / 62%）

主人（左键点开面板、拖完两条横条之后）回了两个数：

> **「0.25，62%」**

跟当初调速滑条那次一个流程：**主人调好 → 告诉人家 → 人家固化进代码**。

## 固化在哪

| 位置 | 值 |
|---|---|
| `renderer/renderer.js` 顶部 `OUTLINE` | `width: 0.25`、`depth: 62`（线色 = `rgb(97,97,97)`）、`ring: 0.25` |
| `renderer/index.html` 两条横条的 `value` | `0.25` / `62`（页面一打开就是这个值） |
| `scripts/make-edge-masks.js` 默认 `lineWidth` | 0.6 → **0.35** —— 掩码的"预加粗"也跟着降到最细一档（屏上 ≈0.25px），不然滑条拖到 0.25 时线还是原来那 0.5px 粗，**滑条下半段等于没作用** |

顺带把加粗公式改成按 0.25 起步：

```js
const grow = Math.max(0, OUTLINE.width - 0.25);   // 0.25 → 不加粗；4 → 加粗 3.75px
```

## 自检也跟着改了（104/104 ✅）

两个断言原来**写死了默认值**（"恢复默认 92 → rgb(20,20,20)"），主人一改默认值就会假报警 ✗。
现在改成：

| 断言 | 做法 |
|---|---|
| 拖"粗细"滑条 | 只在**同一个深浅**下比 0 粗 和 4 粗（不依赖默认值） |
| 拖"深浅"滑条 | 只在**同一个粗细**下比 浅 和 深 |
| **新增**：「滑条的默认值 = 主人定死的那两个数」 | 把两个滑条重置成 `defaultValue` → 断言 `0.25 / 62 / rgb(97,97,97)` |
| 外轮廓像素取证 | 线色从状态里读（`rgb(97,97,97)`），不再写死 20 —— 换深浅也不会假报警 |

```
PASS  拖"描边粗细"滑条 → 画布上的线条跟着变粗/消失  (粗细0时深色像素=3152，粗细4时=3761)
PASS  拖"黑白深浅"滑条 → 线条颜色跟着变深/变浅  (深浅20 → rgb(204,204,204)；深浅95 → rgb(13,13,13))
PASS  滑条的默认值 = 主人定死的那两个数（0.25px / 62%）  (粗细=0.25px 深浅=62% 线色=rgb(97,97,97))
PASS  部件描边掩码已接入（外轮廓=0.25px）
PASS  每一帧都套用描边，且描边真的画在轮廓上（取样点 11 个）
自检 104/104 ✅　打包版 104/104 ✅
```
