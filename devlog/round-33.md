## ② 新的本地台词表：6 组 19 句

`lib/action-lines.js` 的 `LOCAL_LINES` 整份重写。**没有尾巴、没有点心、没有"人家"**：

```js
const LOCAL_LINES = {
  click:    ['あら，你戳到我了呢♪', '在的在的，我一直都在哦', '今天也一起喝杯茶吧？', '你手边这点小事，都好新鲜呀'],
  pat:      ['摸摸头…好舒服呢，谢谢你', 'ふふ，那我给你倒杯茶吧♪', '再、再多摸一下也可以哦'],
  angry:    ['もう…我要生气了哦', '太过分的话，就不给你茶喝了', '嘿——（轻轻一下）…啊，我是不是太用力了'],
  happy:    ['今天有你在，什么都很甜呢', 'ふふ，今天的心情，比红茶还暖', 'ふふ，那我们再来一杯茶吧'],
  happyOff: ['好啦，我把杯子收起来', '那，先这样，我随时都在哦'],
  idle:     ['我去泡壶茶，你忙你的就好', '要不要一起喝杯茶？', '今天想弹点什么呢…你有什么想听的吗', '我只是觉得，这样安安静静的真好呀'],
};
```

写的时候守了三条：

- **不写点心**：原案的"和菓子""大福""炒面"全删；`happy` 里那个"甜"是比喻，不是吃食。
- **不写尾巴**：`happy` 原来是「（尾巴摇摇）」、`idle` 原来是「（尾巴轻轻晃了晃）」，两处都换掉了。
- **口气统一**：礼貌体、句子短、慢而软，收句用"呢 / 哦 / 吧 / 呀"；生气档最重只到"不给你茶喝了"。

## ③ 四个时机的提示词片段也得跟着改

台词换了，塞进 system 的 `ACTION_HINTS` 必须同步，否则**离线是她、接上模型就变成另一个人**：

`idle` 的"提一下白饭"改成"**提一下刚泡好的茶**"；`happyOff` 原文不含旧人设的词，未改。

### 本轮修掉的一处「测试自己不稳」（真 bug，不是功能问题）

第 32 轮写的两条空闲断言（"该开口了" 与 "每日上限"）**依赖随机数**：
闸门里的抖动是 ±25%，而注入的时间是 `60 分钟 × 1`、阈值上限是 `60 × 1.25 = 75 分钟` ——
随机数偏大时就变成 `too_soon`，于是**同一条断言一次绿、一次红**。
第一次跑就抓到它红了，第二次又绿了；要不是连跑，这种"偶发红"会被当成环境抖动糊过去。

修法：把注入的"上次开口 / 上次主人理她"时间改到**3 小时前**，任何抖动下都稳稳超过阈值。
教训记下来：**含随机抖动的闸门，测试注入值要留足余量，不能贴着边界**。

### 新增的第 3 条断言：两个文件不许各说各话

台词分散在 `lib/action-lines.js`（权威）和 `renderer/renderer.js`（投影），换人时**两边都要改**。
所以新增一条：把渲染层的 `LINES` 取回来和权威表**逐字对一遍**，任何一组不同就红。
